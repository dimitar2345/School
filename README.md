# School OOP Projects Repository
A collection of Object-Oriented Programming (OOP) examples and assignments in C#. This repository contains multiple practical projects demonstrating core OOP concepts.
## 📁 Project Structure
```
School/
├── Bank/              # Banking system example
├── Domashno/         # Homework assignment projects
├── Library/          # Library management system
├── Shop/             # E-commerce/shop example
├── Zoo/              # Zoo management system
├── SD/Stadion/       # Stadium/field management
├── DB/               # Database-related files
└── tests/            # Test cases
```
## 🎯 Purpose
This repository serves as a learning resource for students studying Object-Oriented Programming. Each project demonstrates:
- Class and object creation
- Encapsulation principles
- Inheritance and polymorphism
- Data structures and algorithms
- File I/O operations
## 🛠️ Technologies
- **Language**: C# (.NET)
- **Framework**: .NET Framework / .NET Core (as appropriate for each project)
- **Build System**: MSBuild (.csproj files)
## 📚 Key Projects
### Bank
A simple banking system demonstrating account management, transactions, and interest calculations.
### Library  
A library management system showing book tracking, member management, and loan processing.
### Shop
An e-commerce example with product catalogs, shopping carts, and order processing.
### Zoo
A zoo management system featuring animal care, visitor tracking, and exhibit management.
## 🚀 Getting Started
1. **Clone the repository**
```bash
git clone <repository-url>
cd School
```
2. **Navigate to a project**
```bash
cd Bank  # or any other project directory
```
3. **Build and run**
```bash
dotnet build
dotnet run
```
