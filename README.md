# School OOP Projects Repository

A collection of Object-Oriented Programming (OOP) examples and assignments in C#. This repository contains multiple practical projects demonstrating core OOP concepts, including class and object creation, encapsulation, inheritance, polymorphism, data structures, algorithms, and file I/O operations.

---

## 📁 Project Structure

```
School/
├── Bank/              # Banking system example
├── Domashno/         # Homework assignment projects
├── Library/          # Library management system
├── Shop/             # E-commerce/shop example
├── Zoo/              # Zoo management system
├── SD/Stadion/       # Stadium/field management
├── DB/               # Database-related files
└── tests/            # Test cases
```

---

## 🎯 Purpose

This repository serves as a learning resource for students studying Object-Oriented Programming. Each project demonstrates:

- **Class and object creation**: Understanding how to define and use classes and objects.
- **Encapsulation principles**: Implementing data hiding and access control.
- **Inheritance and polymorphism**: Creating hierarchical relationships between classes and enabling flexible behavior.
- **Data structures and algorithms**: Applying fundamental data structures and algorithmic logic.
- **File I/O operations**: Reading from and writing to files for data persistence.

## 📚 Key Projects

### 🏦 Bank
A simple banking system that demonstrates:
- Account management (savings, checking, etc.)
- Transaction processing (deposits, withdrawals, transfers)
- Interest calculation and compounding
- User authentication and access control

**Features**:
- Account creation and deletion
- Transaction history tracking
- Balance inquiry
- Interest calculation based on account type

### 📚 Library
A library management system that shows:
- Book tracking (title, author, ISBN, availability)
- Member management (user registration, borrowing, returning)
- Loan processing (due dates, fines, overdue notifications)
- Search functionality for books

**Features**:
- Book search by title, author, or category
- Member registration and login
- Loan tracking and due date reminders
- Book availability status

### 🛒 Shop
An e-commerce example with:
- Product catalog (item details, pricing, inventory)
- Shopping cart functionality
- Order processing and payment integration
- User account management

**Features**:
- Product search and filtering
- Cart management (add, remove, update items)
- Order placement and confirmation
- Payment processing (simulated)

### 🐆 Zoo
A zoo management system featuring:
- Animal care (feeding, health checks, habitat management)
- Visitor tracking (entry, exit, ticketing)
- Exhibit management (animal enclosures, visitor flow)
- Staff management (employees, roles, schedules)

**Features**:
- Animal information tracking
- Visitor check-in and check-out
- Exhibit layout and visitor flow simulation
- Staff scheduling and role-based access

### 🏟️ SD/Stadion
A stadium/field management system that includes:
- Field booking and scheduling
- Event management (match schedules, ticketing)
- Visitor tracking and attendance
- Staff and volunteer management

**Features**:
- Field availability and booking
- Event planning and ticket sales
- Visitor check-in and attendance tracking
- Staff and volunteer scheduling

### 🗄️ DB
A collection of database-related files and examples, including:
- SQL scripts for database creation
- Data modeling and schema design
- CRUD operations (create, read, update, delete)
- Data querying and reporting

**Features**:
- SQL queries for data retrieval and manipulation
- Database schema design and normalization
- Data import/export functionality
- Reporting and analytics

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd School
```

### 2. Navigate to a Project

```bash
cd Bank  # or any other project directory
```

### 3. Build and Run

```bash
dotnet build
dotnet run
```

### 4. Run Tests (if applicable)

```bash
dotnet test
```
